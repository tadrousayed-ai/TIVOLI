# TIVOLI static website

نسخة ثابتة قابلة للنشر على GitHub Pages. لا تحتاج PHP أو قاعدة بيانات أو لوحة تحكم.

## تشغيلها

افتح `index.html`، أو ارفع محتويات هذا المجلد إلى GitHub Pages.

## البيانات والوظائف

- بيانات الأقسام النشطة والمنتجات والأسعار والأسماء والأوصاف مأخوذة من الجداول المرفقة داخل `catalog-data.js`.
- صور الأقسام والمنتجات المحسّنة موجودة داخل `assets/optimized/categories/` و`assets/optimized/products/`، وشعار TIVOLI في `assets/logo-tivoli.webp`.
- الأقسام تفتح منتجاتها، ويمكن إضافة المنتجات إلى السلة، وحفظ السلة والمفضلة محليًا في المتصفح.
- للمنتجات التي لا صورة لها، تُعرض صورة شعار TIVOLI كبديل.

## تغيير الصور

يمكنك تغيير صورة أي قسم أو منتج لاحقًا من `images.js`. ضع الصورة داخل مجلد الأصول المناسب ثم أضف المسار باستخدام رقم القسم أو المنتج. مثال:

```js
window.TIVOLI_IMAGES = {
  categories: { "1": "assets/optimized/categories/breakfast.jpg" },
  products: { "1": "assets/optimized/products/croissant.jpg" }
};
```

إرسال الطلب والدفع وطلب الحساب لا تتصل بخادم في هذه النسخة الثابتة.

## شاشات الموبايل

التصميم يتجاوب مع الشاشات الصغيرة: قائمة الأقسام والمنتجات قابلة للسحب أفقيًا، مع تكييف أحجام البطاقات والصور والشريط العلوي والسلة للمس.
